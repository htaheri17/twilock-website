Twilock Slideshow Inbox

Prepare ordered photo slides, a title, a caption and hashtags in a local desktop queue. Review the complete draft, then request an upload to the authorized TikTok account’s inbox. The account owner finishes editing and decides whether to publish in TikTok.

This tool is currently for Twilock’s operator and the three accounts they manage: @skillsmadesimple, @the_glowupguide and @scrollingexplained. It is not a public signup service or a feature inside the Twilock iPhone app.

How the integration works

  1. Connect the intended account with TikTok Login Kit. The tool verifies the returned username.
  2. Review the numbered original JPEGs and edit the title, caption and hashtags in the local queue.
  3. Host the approved JPEGs on the owned, TikTok-verified twilock.com domain.
  4. Choose Send to TikTok inbox. The tool uses the official Content Posting API in MEDIA_UPLOAD photo mode.
  5. Open TikTok’s inbox notification to review and edit the draft. Publishing is a separate action in TikTok.

The integration does not directly publish or schedule posts. Production access is not approved as of October 24, 2026. Sandbox review demonstrations use new test content and explicit, limited authorization.

Data and access

The desktop queue runs on the operator’s Mac at a loopback address. App credentials, account tokens, draft files and upload receipts remain in its private local state directory. Approved photo files become public on the image host for TikTok to download.
